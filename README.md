# Yonas Amare — Portfolio

Personal portfolio website of **Yonas Amare**, Full Stack Developer.

## Live

Deployed on Vercel.

## Local

Just open `index.html` in a browser, or serve with any static server:

```bash
npx serve .
```

## Deploy on Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → New Project
3. Import the repository
4. Deploy (zero config needed for static HTML)

Or use the Vercel CLI:

```bash
npx vercel
```
